# MakeyStar

Обход блокировок для Discord, YouTube и игр на движке zapret (bol-van) со стратегиями Flowseal.
Один файл, всё настраивает и скачивает сам.

## Как установить

1. Откройте **[последний выпуск](https://github.com/MakeyST/MakeyStar-releases/releases/latest)** и скачайте `MakeyStar.exe`.
2. Положите файл в постоянную папку, например `C:\MakeyStar` (не в «Загрузки», которые вы чистите).
3. Запустите и один раз подтвердите запрос Windows (права администратора). Дальше MakeyStar запускается сам вместе с Windows, без запросов.

## Обновления

Ничего делать не нужно: MakeyStar сам проверяет новые версии и предлагает **«Обновить сейчас»**.
Обновление скачивается отсюда, проверяется (подпись и контрольная сумма) и ставится за несколько секунд, настройки сохраняются.
Проверить вручную: **Настройки → Обновления MakeyStar → Проверить обновления**.

## Проверка файла

Рядом с каждым `MakeyStar.exe` лежит `MakeyStar.exe.sha256` — контрольная сумма SHA-256.
